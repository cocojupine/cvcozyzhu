# English CV package

This folder contains the current English resume and the materials used to produce it.

- `final/Kesi_Zhu_CV_EN.pdf`: final one-page English resume
- `source_materials/CV_Kesi_latest_CN.pdf`: latest Chinese source resume
- `source_materials/CV_Kesi_previous_EN.pdf`: previous English layout reference
- `working/generate_resume.py`: editable ReportLab source
- `working/translation_and_editing_notes.md`: translation and editorial decisions
- `working/assets/`: portrait and university logo assets extracted from the latest Chinese PDF
- `preview/Kesi_Zhu_CV_EN_page-1.png`: rendered final-page preview used for visual QA

To regenerate the PDF, run `working/generate_resume.py` with the bundled Python runtime or any Python environment containing ReportLab.
